# VK Social Graph

Учебное консольное приложение на Java 21 для построения графа знакомств участников БСМО-11 и БСМО-12 по доступным данным VK API.

Приложение:

- читает ссылки на профили из CSV;
- получает друзей участников и друзей их друзей;
- строит неориентированный граф;
- считает общих знакомых участников;
- оценивает центральность по посредничеству, близости и собственному вектору;
- сохраняет CSV, GraphML, интерактивный HTML и Markdown-отчёты;
- поддерживает checkpoint-кеш и офлайн-анализ накопленных данных.

## Стек

- Java 21;
- Maven;
- picocli;
- `java.net.http.HttpClient`;
- Jackson;
- SLF4J + Logback;
- JUnit 5 + AssertJ;
- HTML Canvas + JavaScript для визуализации.

Spring Boot не используется: приложение является пакетным и не запускает веб-сервер.

## Структура данных

- `L0` — 31 исходный участник двух групп;
- `L1` — друзья исходных участников;
- `L2` — друзья пользователей L1;
- вершина — пользователь VK;
- ребро — подтверждённое отношение дружбы.

Граф неориентированный и простой. Рёбра канонизируются, дубликаты и петли не сохраняются.

## Входные файлы

- `data/bsmo-11.csv` — БСМО-11;
- `data/bsmo-12.csv` — БСМО-12;
- `data/bsmo-all.csv` — объединённый список из 31 участника.

Формат:

```csv
vk_url
https://vk.ru/example
https://vk.ru/id123456
```

## Настройка

Скопируйте `.env.example` в `.env` и укажите токен:

```dotenv
VK_ACCESS_TOKEN=ваш_токен
VK_CRAWL_DEPTH=2
VK_MAX_LEVEL2_PARENTS=all
VK_L2_WORKERS=1
VK_EXECUTE_BATCH_SIZE=1
VK_REQUEST_DELAY_MS=1500
VK_LOG_LEVEL=INFO
VK_CACHE_DIR=state/friends
VK_CACHE_TTL_HOURS=168
```

`.env`, `state/`, `out/`, `target/` и настройки IDEA исключены из Git.

## Запуск сбора из IntelliJ IDEA

Запустите метод `main` класса:

```text
ru.vasilyev.mirea.vkgraph.Main
```

Без аргументов используются `data/bsmo-all.csv`, команда `all` и каталог `out`.

Через JAR:

```bash
./mvnw clean package
java -jar target/vk-social-graph-1.0-SNAPSHOT-all.jar all \
  --input data/bsmo-all.csv \
  --depth 2 \
  --max-level2-parents 1000 \
  --output out
```

## Checkpoint

После каждого обработанного пакета список друзей сохраняется в `state/friends`. Повторный запуск использует актуальные записи и запрашивает только отсутствующие данные.

Кешируются успешные ответы и постоянные ошибки приватности, удаления или отсутствия профиля. Ошибки авторизации, сети и ограничения частоты не кешируются.

## Офлайн-анализ зафиксированного среза

Если дальнейший сбор ограничен Flood control, граф можно построить без токена и сетевых запросов:

```bash
./mvnw package
java -jar target/vk-social-graph-1.0-SNAPSHOT-all.jar offline \
  --betweenness-samples 1024
```

В IntelliJ IDEA укажите в `Program arguments`:

```text
offline --betweenness-samples 1024
```

Команда:

1. читает все checkpoint-файлы;
2. строит индуцированный граф кешированных пользователей;
3. вычисляет центральности только для исходных участников;
4. создаёт полный набор результатов.

Близость рассчитывается точным BFS с поправкой Wasserman–Faust. Центральность собственного вектора вычисляется степенным методом. Посредничество оценивается алгоритмом Brandes по детерминированной выборке источников с фиксированным seed `42`.

## Метрики

Для пары участников `A` и `B`:

```text
mutual(A, B) = |friends(A) ∩ friends(B)|
```

`shared_unique` — количество уникальных друзей участника, которые также являются друзьями хотя бы одного другого исходного участника.

`shared_sum` — сумма попарных пересечений со всеми участниками. Один знакомый может учитываться несколько раз.

`seed_degree` — количество прямых друзей среди 31 исходного участника.

Центральности:

- посредничество — участие вершины в кратчайших путях;
- близость — обратная средняя удалённость от доступной части графа;
- собственный вектор — связь с другими структурно значимыми вершинами.

## Результаты

Готовый зафиксированный результат находится в `results/final`.

Основные файлы:

- `practice_report.md` — итоговый текст практической работы;
- `centrality.csv` и `centrality_report.md` — центральности участников;
- `seed_ranking.csv` и `pair_mutual.csv` — общие знакомства;
- `nodes.csv` и `edges.csv` — полный наблюдаемый граф;
- `graph.graphml` — импорт в Gephi/Cytoscape;
- `graph.html` — интерактивная визуализация;
- `unavailable_profiles.csv` — недоступные профили и причины.

Зафиксированный граф содержит 7482 вершины и 225377 рёбер. Крупнейшая компонента содержит 7481 вершину.

## Ограничения

- результат отражает только доступный наблюдаемый срез на дату сбора;
- закрытые и удалённые профили могут быть представлены неполно;
- зафиксированный граф не является всей социальной сетью VK;
- выборка сформирована вокруг друзей исходных участников;
- ограничение VK Flood control не обходится программой;
- токен и checkpoint-кеш не публикуются.
